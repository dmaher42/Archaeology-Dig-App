# NAIDOC Exploration Placeholder Assets

This folder contains the first playable NAIDOC exploration PNG asset pack.

Current assets:

- `backgrounds/naidoc-country-discovery-panorama-2026.png` - AI-generated classroom-safe panorama background.
- `player/student-explorer-sprite-strip-384x192.png` - four-frame transparent student explorer strip.
- `markers/knowledge-marker-sheet-512x128.png` - marker states: available, collected, locked, info.
- `props/naidoc-classroom-props-sheet-1024x256.png` - props for archaeology, river, milestone and reflection areas.

Replace or add artwork here when ready:

- `backgrounds/` - area backgrounds or parallax layers for river, Country, archaeology and milestone scenes
- `markers/` - investigation marker icons or small object art
- `player/` - student explorer sprite or simple walking frames
- `props/` - river plants, signs, artefact-recording tools, milestone displays and classroom-safe local objects

Keep sacred, secret or restricted cultural material out of this public classroom asset folder.
