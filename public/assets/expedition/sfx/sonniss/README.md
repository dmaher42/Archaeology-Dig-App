# Sonniss GDC 2026 — curated game SFX

Hand-picked clips from the Sonniss GDC 2026 Game Audio Bundle (royalty-free,
see LICENSE-GDC-Game-Audio.pdf). Trimmed from the original 24-bit/96kHz WAVs
to short 44.1kHz ogg clips for web delivery. Wired into the SFX manifest in
`src/App.jsx` (`EXPEDITION_AUDIO_TRACKS.sfx`).
