# Standalone Game Rule

This document exists to protect Lost Site Expedition from drifting into a classroom worksheet experience.

The game must work first as a standalone adventure game.

The player should want to play because the movement, exploration, danger, mystery, bosses, upgrades, secrets, atmosphere, and discovery moments are satisfying on their own.

The educational value must emerge through gameplay and world interaction, not through constant interruption.

## Core Rule

Game first. Learning through the world.

Do not build disconnected educational layers that stop the player repeatedly for quiz questions, long explanations, worksheet-style tasks, or excessive exposition during core gameplay.

## Correct Player Fantasy

The player fantasy is:

> I am an explorer or archaeologist uncovering a dangerous lost site.

Not:

> I am completing a history worksheet inside a game.

## Educational Design Direction

Historical learning should emerge through:

- environmental storytelling
- murals and inscriptions
- ruins and architecture
- excavation choices
- artefacts and evidence
- preservation systems
- field notes
- tool use
- interpretation systems
- route discovery
- optional lore and discoveries
- archaeology-like actions embedded into gameplay

## Avoid

Avoid relying on:

- disconnected quiz popups
- long educational text walls during action gameplay
- constant pausing for explanation
- fake worksheet interfaces
- overexplaining historical facts
- educational tasks that interrupt pacing

## Preferred Design Approach

Prefer:

- discovery through exploration
- archaeology through gameplay verbs
- evidence interpretation through puzzles and systems
- environmental clues instead of exposition
- optional deeper lore for interested players
- cinematic discovery moments
- meaningful rewards tied to archaeology systems

## Character Rule

Characters should feel like believable game characters first.

Asha should guide, warn, protect, and deepen the mystery of the site. Asha should not become a lecture-delivery system.

The Sphinx should feel intimidating, intelligent, and ancient, not like a tutorial popup.

The archaeologist should represent evidence, discovery, excavation, and interpretation.

## Excavation Rule

Excavation should feel like rewarding archaeological detective work.

The excavation layer should contain:

- meaningful evidence decisions
- hidden finds
- reconstruction
- interpretation
- careful excavation
- evidence quality consequences
- route and reward logic

It should not become a static administration screen.

## Core Design Goal

A player with no connection to the classroom unit should still want to play Lost Site Expedition as a standalone archaeology adventure.

If the game remains compelling without the educational context, the educational layer becomes stronger rather than weaker.
