The new plan
1. Platformer = the main playable adventure

Each expedition should take time. Not 2–3 minutes. More like a proper stage with sections.

A good target would be:

Type	Length
Short classroom demo stage	5–8 minutes
Normal expedition stage	12–20 minutes
Major civilisation expedition	20–35 minutes
Full Egypt/Tutankhamun arc	multiple stages

This means students can play across multiple lessons, and it feels like a real game rather than a quick activity.

2. Each expedition should have zones

Instead of one small side-scrolling level, each expedition should be made of connected areas.

Example: Egypt Expedition

Stage 1: Desert Approach

Purpose: movement, jumping, hazards, basic enemies
Reward: first map fragment

Stage 2: Valley of the Kings

Purpose: vertical platforms, caves, hidden routes, stronger hazards
Reward: tomb location clue

Stage 3: Sealed Stairway

Purpose: puzzle-platforming, switches, locked doors, ancient mechanisms
Reward: discovery entrance unlocked

Stage 4: Tomb Threshold

Purpose: tense, slower platforming, fragile chambers, final guardian
Reward: excavation site unlocked

Then:

Discovery Entrance → Base Camp → Excavation Site → Lab/Report

That gives the platformer proper length and importance.

3. The platformer should have its own progression

The platformer needs reasons to keep playing even if the educational layer was removed.

So it needs:

health system
checkpoints
upgrades
movement abilities
enemies/guardians
collectibles
secrets
optional rooms
level goals
boss or escape sequences
performance ratings

The game should be fun because of:

movement
exploration
challenge
reward
atmosphere
progression

Not because students are being asked questions.

4. Make platforming rewards feed the archaeology system

This is how the two parts connect without weakening either one.

During platforming, students collect things that help later at the excavation site.

Examples:

Platformer item	Later use
Map fragment	Reveals likely excavation grid
Lens piece	Improves photography score
Brush kit	Reduces artefact damage
Notebook page	Unlocks extra interpretation clue
Seal fragment	Opens chamber entrance
Supply crate	Gives more excavation attempts
Ancient inscription shard	Helps lab interpretation
Relic dust / currency	Upgrades Base Camp

This keeps the platformer game-focused, but it still matters to the archaeology loop.

5. Use “Discovery Entrance” as the major transition moment

This should be a big emotional reward.

After a long platforming stage, the player reaches something like:

sealed tomb door
buried stairway
collapsed archive gate
ancient cave entrance
lost city wall
ceremonial site marker

Then the game slows down and says:

“You have found the site. Return to Base Camp to prepare the excavation.”

This gives the player a strong sense of achievement.

6. Base Camp becomes the bridge between fun and learning

Base Camp should not feel like a worksheet screen. It should feel like a game hub.

At Base Camp, players can:

upgrade tools
view collected relics
choose next expedition
prepare excavation kit
check mission objectives
talk to team members
review evidence board
unlock new areas
improve camp facilities

This gives you a Diablo-style loop:

Go out → survive → collect → return → upgrade → go deeper

But archaeology-themed.

7. Excavation becomes the “high-value reward mode”

The excavation should feel like opening the treasure chest after a long dungeon — but with archaeology rules.

After the platformer expedition, the player earns access to a site.

Then they must:

survey
place grid
excavate carefully
photograph in situ
catalogue
preserve
send to lab
make interpretation

This matches the unit plan’s excavation sequence: survey, grids, excavate, map and lab analysis.

So the platformer gives the excitement.
The excavation gives the meaning.

What this means for the platformer design

The platformer should be built like a proper 2D adventure game.

Each expedition needs:
A. Movement identity

Each civilisation area should feel different to play.

Example:

Expedition	Platformer feel
Egypt	sand slides, collapsing blocks, tomb traps
China	bamboo bridges, river crossings, wall towers
Mungo	open landscape, careful navigation, environmental clues
Greece	temple ruins, columns, vertical climbing
Rome	aqueducts, crumbling roads, underground tunnels
Indus	water channels, brick city platforms, drainage tunnels
B. Enemy/hazard identity

Not everything needs to be combat. Hazards can carry the challenge.

Examples:

falling rocks
bats
scarabs
snakes
unstable bridges
collapsing floors
mud pits
rolling stones

flood channels
ancient mechanisms
C. Secrets

This is what makes students replay.

Each stage should include:

optional challenge paths
secret relics
alternate route
rare evidence fragment
bonus chamber
shortcut unlocked later with upgrades

At the end of each platformer stage, give a game-style rating:

site discovery rank

This makes it feel like a real game.
